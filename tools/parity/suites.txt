# The parity suites, as <fixture> <cases> [subdir] triples.
#
# Fixture and case names do not always match -- one fixture often serves
# several case files, and one case file is sometimes worth running twice from
# different directories -- so the pairing is listed here rather than guessed
# from the filenames. run_all.sh reads this file; add a line here when you add
# a suite, or it will not run in the gate.
#
# A third field runs every case in that suite from that subdirectory of the
# worktree instead of from its root.
